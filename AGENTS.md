# Willow brand

All visual and written work in this project follows `willow-brand/AGENTS.md` (Willow brand v2). Use `willow-brand/tokens/tokens.css` for colours and fonts, and the files in `willow-brand/logos/` for logos. Never hard-code brand colours, substitute fonts or redraw logos.

`willow-brand/` is a copy of github.com/weepingwillowwhisperer/willow-brand. Do not edit it here: change the brand repository, then run `sh willow-brand/update.sh` from this project's root.
